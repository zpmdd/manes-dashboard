# 内置中文字体

仅加载当前选定字体，本地部署不依赖外部字体服务。英文使用项目现有 Manrope，指标数字使用 Michroma。

- **MiSans**：官方 Regular 400 / Medium 500 WOFF2，默认字体。来源：https://hyperos.mi.com/font/zh/download/ 。许可：`LICENSE-MiSans.pdf`。
- **霞鹜文楷 GB Lite**：v1.522 原版 Medium 500 TTF，与用户选定的 05 样本一致。来源：https://github.com/lxgw/LxgwWenkaiGB-Lite/releases/tag/v1.522 。许可：`LICENSE-LXGWWenKaiGBLite.txt`。

保留完整原版字库，未裁切业务用字，也未转换或伪造字重。页面继续禁用合成粗体；没有对应字重时由浏览器选择该字体最近的原生字重。
