# Nexus · 全域运行视窗

根据用户提供的 `1 - 1.mov` 与配套 JPEG 复刻的交互原型。保留烟灰玻璃、奶油白字体、深色卡片与胶囊导航，把建筑场景换为可旋转、缩放、逐级下钻的中国行政区沙盘。

## 本地运行

需要 Node.js 20.19+；本次使用 Node.js 24.15.0 验证。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

已附完整的本地地图数据与字体。运行时不需要地图 API Key、互联网字体、在线底图或外部 HDR。

```sh
npm run check
npm run build
npm run preview -- --host 127.0.0.1 --port 5174
```

内网静态服务以 `dist/client` 为网站根目录即可。直接双击 `index.html` 的 `file://` 方式不支持读取 GeoJSON，应使用 HTTP 静态服务器。当前资源路径从 `/` 开始；若部署到子目录，需要同时调整 Vite base 和数据请求前缀。

模板附带的 Sites worker 文件保留；当前交付未进行外网发布。

## 使用

- 左键拖动旋转，右键拖动平移，滚轮缩放。右侧按钮支持放大、缩小、旋转、俯视，顶栏罗盘恢复初始视角。
- 点击区域下钻；左上区域名称可打开选择器并搜索名称或六位代码；面包屑及返回按钮可返回父级。
- Home 恢复默认图层；Smart City 开启热力；Transportation 聚焦道路；Governance 打开区域管理。
- 图层面板可控制道路、监测光柱、区域连线、热力、标签，并切换质感与流畅模式。
- 全国 → 湖北省 → 十堰市 → 丹江口市可查看精细道路样区；区域选择器也有快捷入口。
- 数据说明中保留来源链接和渲染统计。统计是手动快照，含反射等通道，并非 FPS。

## 技术与性能

React 19、Three.js r186、React Three Fiber 9、Drei 10、Vite 6。仪表由 Canvas 绘制，界面由 CSS 原生玻璃与排版实现，图标为 Phosphor，字体为本地 Michroma / Manrope。

单个共享 WebGL 场景位于所有玻璃组件后方。地图为真实 GeoJSON 挤出网格，保留多岛和内环；道路按类别合并线段，省区多岛按材质合并绘制组，保留点击区域能力。

- 按需渲染：没有默认自动旋转或常驻动画循环。
- 单次生成环境与接触阴影；地面模糊反射使用 512px 渲染目标。
- 质感模式最多约 369 万场景像素，流畅模式最多约 207 万场景像素；UI 仍按浏览器原生分辨率绘制。
- 当前行政区与道路按需读取，不一次下载并创建所有区县网格；切换后释放旧几何。
- 独立渲染组件避免面板文字更新触发三维重绘。

本机浏览器常规全国帧由 1355 次绘制调用降低至 347 次，同为 575817 个提交三角面；初次阴影生成的帧开销更高。已检查 1120×718、1920×1080、3840×2160 和窄窗口。未据此承诺现场所有设备恒定 60 FPS。

## 数据与范围

`public/data` 包含 3238 个层级索引条目、364 个行政区集合文件及逐区域道路文件。索引含全国、特别行政区等数据条目，并不等于当前官方行政区数量。区县叶节点复用父级集合，按 adcode 过滤。

- 行政边界复用 Daoyan 项目，原始来源 DataV.GeoAtlas；全国省界另取同源集合。
- 全国道路来自 Natural Earth 1:10m 概化主干路，不能作为完整全国高速、国道数据。
- 丹江口复用危货项目已经取得的 OSM 道路，WGS84；包含 G70、G59、G209、G241、G316 等编号。道路断段保持独立，不把同名路线强行连成直线。
- 边界源未声明 CRS，精确坐标一致性、行政区时效及现场业务完整性尚未验收；台湾数据仅到省级外轮廓，直辖市等按实际源数据层级展开。
- 监控数字、光柱、连线与热力均为演示；左栏 80% 为示意接入覆盖率，尚未连接业务监控 API。

详细来源见 `public/data/SOURCES.md`，源文件散列见 `public/data/provenance.json`。

## 代码入口

- `src/App.jsx`：界面、区域导航、本地加载和状态。
- `src/MapScene.jsx`：网格、灯光、道路、相机、性能读数。
- `src/geo.js`：投影、层级、内环与标签定位。
- `src/styles.css`：材质、排版、断点。
- `scripts/check.mjs`：全量层级与环坐标检查、内环/多岛、道路编号检查。
- `scripts/prepare-geo.py`：由用户原始数据重新准备离线包；该维护脚本依赖 Shapely 及脚本声明的本地源目录，不是页面运行依赖。

视觉核对与保留差异见 `design-qa.md`。
