# MANES · 全域运行视窗

<img src="public/brand/manes-icon.svg" alt="Manes工作室 · 构域标志" width="88" height="88" />

Manes工作室。品牌采用已选定的③「构域 / SPATIAL CORE」标志：开放等轴空间、中央 M 负形与暖白 / 香槟三平面，沿用烟灰玻璃视觉。页面和浏览器图标统一使用精修矢量稿。[品牌资源与生成提示词](docs/brand/README.md)。旧默认品牌会自动迁移为 MANES，用户自定义名称和已保存画布保持不变。

根据用户提供的 `1 - 1.mov` 与配套 JPEG 复刻的交互原型。保留烟灰玻璃、奶油白字体、深色卡片与胶囊导航，把建筑场景换为可旋转、缩放、逐级下钻的中国行政区沙盘。基线之上已改为可配置的运行监测大屏，默认展示设备、在线率、流量趋势、区域排行与运行事件。

## 本地运行

需要 Node.js 20.19+；基线使用 Node.js 24.15.0，本轮编辑器使用 Node.js 25.9.0 验证。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

已附完整的本地地图数据与字体。运行时不需要地图 API Key、互联网字体、在线底图或外部 HDR。

```sh
npm run check
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 5174
```

内网静态服务以 `dist/client` 为网站根目录即可。直接双击 `index.html` 的 `file://` 方式不支持读取 GeoJSON，应使用 HTTP 静态服务器。当前资源路径从 `/` 开始；若部署到子目录，需要同时调整 Vite base 和数据请求前缀。

模板附带的 Sites worker 文件保留；当前交付未进行外网发布。

## 使用

- 左键拖动旋转，右键拖动平移，滚轮缩放。右侧按钮支持放大、缩小、旋转、俯视，顶栏罗盘恢复初始视角。
- 点击区域下钻；左上区域名称可打开选择器并搜索名称或六位代码；面包屑及返回按钮可返回父级。
- 运行总览恢复默认图层；数据监测开启热力；交通网络聚焦道路；区域管理打开区域选择器。导航名称可配置。
- 图层面板可控制离线道路底图、道路、监测光柱、区域连线、热力、标签，并切换质感与流畅模式。离线道路底图默认关闭；开启后贴合行政区表面，跟随旋转、缩放和下钻。图片自带的道路与地名不能单独隐藏。
- 全国 → 湖北省 → 十堰市 → 丹江口市可查看精细道路样区；区域选择器也有快捷入口。
- 数据说明中保留来源链接和渲染统计。统计是手动快照，含反射等通道，并非 FPS。
- 车辆图层默认展示提供的 5 辆车，点击号牌标签查看全部 15 个字段；重叠标签通过引线错开，坐标保持原值。地图下方可定位全部车辆，详情中可定位单车，图层面板可开关车辆显示。
- 车辆数据位于 `src/vehicles.js`，是 GPS 时间 `2026/9/13 00:00` 的固定快照。沿用原字段 `PALTE_COLOR`，海拔、里程空值显示“未提供”，报警和状态保留完整二进制字符串；未推断编码含义或做未经确认的坐标系转换。
- 标题、导航、地图控件、图例与数据卡片使用独立的烟灰玻璃底色，地图放大或开启浅色道路底图后仍保持文字与按钮对比；保留半透明、模糊、高光和原有地图材质。

## 可复用大屏编辑器

右上角「编辑大屏」进入自由画布。支持 20 种业务组件和一个共享三维地图，每个画布最多 40 个业务组件。可添加、修改、复制、删除、单选八向缩放和精确输入尺寸，支持多选整组移动、锁定、隐藏、图层顺序、撤销/重做与预览。保存画布后在当前浏览器生效，未保存退出会提示。

- 基础组件：指标卡、仪表盘、折线图、面积图、柱状图、条形图、环形图、表格、目标进度、状态矩阵、公告、数字时钟。
- 八种专业图表：多系列折线、堆叠柱状图、双轴组合图、雷达图、散点气泡图、矩阵热力图、漏斗图、矩形树图。可配置图例、标签、配色，以及适用图表的轴名称、单位、平滑和区间缩放。
- 按 `Shift/⌘/Ctrl` 点击多选。网格步长为 0.5–5%，磁吸按 2–16 CSS 像素匹配画布及可见组件的边与中心；按住 `Alt` 临时关闭吸附。支持六种对齐、水平/垂直等距、同宽/同高；锁定项不参与移动、批量排列和删除。
- 全局名称、导航文字和时钟可配置；组件可更换内容、材质、单位、1–100 条记录、表格列/列名。
- 四套内置布局：运行总览、双侧监测、数据分析、业务洞察；可另存最多 10 份本地模板。JSON 导入导出包含布局、数据绑定和静态数据，最大 2 MB。旧 v1 和缺少扩展选项的 v2 配置可导入，显式保存才写入浏览器本地存储。
- 数据源支持静态 JSON、CSV 与 HTTP GET。识别数据后可选择多数组路径、预览字段类型与空值、检查适配结果，再按明确映射推荐创建组件；源与组件一次写入草稿，可整体撤销。点路径映射、求和/平均/首条汇总和 `{adcode}` 区域参数均可配置。
- 专业图表校验必填字段及需要唯一的类别组合，缺值与缺少的趋势点不会伪补 0。自定义组件切换类型保留业务单位和映射，改接外部源时清除演示单位与轴名称。
- 组件库、属性、模板、数据源与设置的加载失败仅影响各自面板，画布草稿与保存工具继续保留；错误弹窗可关闭后保存。
- 数据错误可见，更新失败保留上次数据；自定义数据不会回退为示例。数据源或区域变更时取消过期请求，隐藏页面暂停轮询。

使用步骤、八种专业图的字段契约和接口约定见 [编辑与对接指南](docs/editor-guide.md)。附带 [基础监测示例](public/data/examples/monitoring.json)与 [专业图表示例](public/data/examples/professional.json)，后者用七个命名数组覆盖八种专业图，均为固定虚构演示快照。模板保存在本地浏览器；跨设备通过 JSON 迁移。服务端配置中心、用户权限、鉴权代理和真实监控业务仍需项目实施。

## 技术与性能

React 19、Three.js r186、React Three Fiber 9、Drei 10、Vite 6。基础指标与图表使用 SVG / CSS，八种专业图表使用按需加载的 ECharts 6.1；界面沿用 CSS 玻璃与排版，图标为 Phosphor，字体为本地 Michroma / Manrope。

单个共享 WebGL 场景位于所有玻璃组件后方。地图为真实 GeoJSON 挤出网格，保留多岛和内环；道路按类别合并线段，省区多岛按材质合并绘制组，保留点击区域能力。

- 按需渲染：没有默认自动旋转或常驻动画循环。
- 单次生成环境与接触阴影；地面模糊反射使用 512px 渲染目标。
- 质感模式最多约 369 万场景像素，流畅模式最多约 207 万场景像素；恢复视角、切换质量与窗口缩放统一沿用该预算，UI 仍按浏览器原生分辨率绘制。
- 当前行政区与道路按需读取，不一次下载并创建所有区县网格；切换后释放旧几何。
- 相机裁剪范围在每个实际绘制帧按当前位置更新，覆盖下钻过渡、滚轮、按钮缩放与平移；补缝底层使用深度偏移，避免区级下钻后缩放出现三角形遮挡。仍保持按需绘制。
- 离线底图开启后才读取 `public/roadmap`：保留一张全国概览纹理，视野变化停止 160ms 后，按视野中心原图像素的屏幕投影尺寸及实际渲染像素比选择细节层级。细节覆盖整个可见画布（含卡片后方），裁到已有瓦片范围，仅受显卡纹理尺寸限制；缺失位置保留概览。底图表面保留原图对比度，免受灯光、金属反光与色调映射冲淡，侧面仍保留三维材质。切换、关闭时取消旧请求并释放纹理，复用现有行政区网格与绘制调用。
- 独立时钟和 memo 业务模块隔离更新。行政区 hover 下沉到各自组件，避免整个场景协调以及接触阴影重复计算。
- 专业图表及 ECharts 独立分块，只有使用时加载；字段识别和推荐随编辑面板加载。专业图实例随尺寸、数据和配置更新，卸载时释放，并尊重系统减少动态效果的设置。
- HTTP 按配置间隔轮询，同源多组件共享结果，页面隐藏时暂停；时钟独立更新。质量、反射和地图几何参数保留基线值。
- 单选和多选拖动用浏览器帧回调预览位置，松手时只提交一步历史；地图移动与缩放同时调整相机构图。

本轮本地构建分块体积如下（KB 为十进制，gzip 为压缩后体积）：

| 分块 | 原始 KB | gzip KB | 加载方式 |
| --- | ---: | ---: | --- |
| 应用主包 | 359.61 | 110.72 | 首屏 |
| 三维地图引擎 | 1,038.73 | 283.90 | 地图可见时提前加载 |
| 专业图表与 ECharts | 690.19 | 235.16 | 使用专业图表时 |
| 字段识别与推荐 `dataInference` | 10.48 | 3.99 | 打开相关编辑面板时 |
| 共享专业图构建逻辑 `professionalCharts` | 11.11 | 4.75 | 图表或推荐功能需要时 |

地图隐藏时不加载三维引擎、行政边界与道路；地图可见时与区域数据并行加载，材质、灯光和几何参数不变。分块体积用于检查加载边界，不代表现场设备帧率或全部首屏资源大小。

基线优化阶段，本机浏览器常规全国帧由 1355 次绘制调用降低至 347 次，同为 575817 个提交三角面；初次阴影生成的帧开销更高。已检查 1120×718、1920×1080、3840×2160 和窄窗口。未据此承诺现场所有设备恒定 60 FPS。

## 数据与范围

`public/data` 包含 3238 个层级索引条目、364 个行政区集合文件及逐区域道路文件。索引含全国、特别行政区等数据条目，并不等于当前官方行政区数量。区县叶节点复用父级集合，按 adcode 过滤。

- 行政边界复用 Daoyan 项目，原始来源 DataV.GeoAtlas；全国省界另取同源集合。
- 全国道路来自 Natural Earth 1:10m 概化主干路，不能作为完整全国高速、国道数据。
- 离线道路底图来自用户提供的 `roadmap` 目录，含 13,822 张 256×256 PNG（约 61.3 MB），已原样复制到 `public/roadmap/{z}/{x}/{y}.png`，可用文件见 `index.json`。采用 XYZ / Web Mercator 寻址，在现有线性经纬度投影中逐像素重投影，避免直接拉伸图片。最高 10 级，更大倍率仅放大现有细节；原文件未附提供商、日期或坐标基准说明，未作测绘级坐标验收。
- 丹江口复用危货项目已经取得的 OSM 道路，WGS84；包含 G70、G59、G209、G241、G316 等编号。道路断段保持独立，不把同名路线强行连成直线。
- 边界源未声明 CRS，精确坐标一致性、行政区时效及现场业务完整性尚未验收；台湾数据仅到省级外轮廓，直辖市等按实际源数据层级展开。
- 默认业务组件与地图光柱、连线、热力为固定演示。组件可绑定自定义数据，地图光柱仍为示例。内置排行按区域总量分配份额，环图含“其他”且总和守恒；附带示例 HTTP 文件不按 adcode 筛选，不代表生产设备清单。

详细来源见 `public/data/SOURCES.md`，源文件散列见 `public/data/provenance.json`。

## 代码入口

- `src/App.jsx`：画布与业务数据接线、独立时钟、区域导航。
- `src/DashboardEditor.jsx` / `src/layout.js`：编辑操作、拖动缩放、历史记录。
- `src/EditorPanels.jsx` / `src/templateLibrary.js`：组件库、属性面板、模板复用。
- `src/dataSources.js` / `src/useDataSources.js` / `src/DataSourcePanel.jsx`：解析、字段映射、共享请求、数据源管理。
- `src/dataInference.js`：数据列表识别、字段分析和组件建议，按编辑功能加载。
- `src/MapPanels.jsx`：复用弹窗、区域选择与地图图层面板。
- `src/DashboardWidget.jsx` / `src/widgetData.js`：复用指标、图表、表格与演示数据适配。
- `src/ProfessionalChart.jsx` / `src/professionalCharts.js`：ECharts 按需渲染、专业图表共享校验与选项构建。
- `src/ConfigPanel.jsx` / `src/dashboardConfig.js`：配置编辑、校验、持久化和默认方案。
- `src/widgets.css` / `src/config.css`：模块与配置面板样式。
- `src/MapScene.jsx`：网格、灯光、道路、相机、性能读数。
- `src/geo.js`：投影、层级、内环与标签定位。
- `src/useRoadmap.js`：本地瓦片选取、纹理加载与表面投影。实现依据：[XYZ 瓦片寻址](https://wiki.openstreetmap.org/wiki/Slippy_map_tilenames)、[Three.js 材质扩展](https://threejs.org/docs/pages/Material.html)。
- `src/styles.css`：材质、排版、断点。
- `scripts/check.mjs`：全量层级与环坐标检查、内环/多岛、道路编号检查。
- `scripts/prepare-geo.py`：由用户原始数据重新准备离线包；该维护脚本依赖 Shapely 及脚本声明的本地源目录，不是页面运行依赖。
