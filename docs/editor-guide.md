# 大屏编辑与数据对接

本编辑器沿用烟灰玻璃、暖白文字和香槟色三维地图。默认业务数值、地图光柱、连线和热力均为演示内容；接入自己的数据后，绑定该源的业务组件显示外部数据。

## 编辑与精细排版

点击右上角 **编辑大屏**。左侧添加组件或选择图层，右侧修改属性。每个画布最多 40 个业务组件，另有一个共享三维地图；再次添加地图会恢复显示，不会创建第二个地图实例。

- **选择与移动**：点击组件或图层选择；按住 `Shift`、`⌘` 或 `Ctrl` 点击可多选，`⌘/Ctrl + A` 选择所有可见组件。拖动选中组件顶部编辑条可整体移动所选可见、未锁定组件，保持相对位置，并受共同画布边界约束。
- **缩放与精确尺寸**：单选组件显示八个缩放控制点。属性栏可输入 X、Y、宽、高百分比；宽高最小为画布的 10%，位置不能超出画布。多选用于整组移动和批量排列，不提供整组比例缩放。
- **网格与磁吸**：网格步长可设为画布的 **0.5–5%**。磁吸匹配画布和其他可见组件的边缘、中心，出现对齐参考线；距离为 **2–16 CSS 像素**，按当前画布尺寸换算。组内成员不互相吸附，隐藏组件不作参考；锁定的可见组件仍可作参考。按住 `Alt` 临时关闭网格和磁吸。
- **对齐与分布**：支持左对齐、水平居中、右对齐、顶对齐、垂直居中、底对齐。单选以画布为参照，多选可选所选组件边界或整个画布。三个以上组件可水平、垂直等距；两个以上可同宽、同高，尺寸采用最先选中的可见组件。等距保留首尾和锁定项，在各固定项之间调整间隙；无法在画布内排开的区段保持原位。
- **锁定与隐藏**：锁定项不参与拖动、键盘移动、批量排列或删除，仍可在属性栏输入精确尺寸。隐藏保留配置，在图层列表中仍可选择，预览和展示态不显示，也不参与组移动与排列。地图的“删除”是隐藏，需先解锁。
- **层级与外观**：业务组件可置顶或置底；可选烟灰玻璃、轻透玻璃、深色面板。标题、副标题、单位、表格列名和图表选项均可修改。

方向键按当前网格步长微移，`Shift + 方向键` 移动 5%；`⌘/Ctrl + D` 复制，`Delete/Backspace` 删除未锁定选项。拖动中按 `Esc` 取消本次移动并恢复全部成员；平时按 `Esc` 取消选择。输入框和打开的对话框不触发画布快捷键。

**撤销/重做**可用工具栏或 `⌘/Ctrl + Z`、`⌘/Ctrl + Shift + Z`，保留最近 50 步。一次整组拖动、批量排列或推荐创建只计一步。**预览**检查展示态，**保存画布**才写入当前浏览器。数据源与全局设置面板中的保存先更新画布草稿，之后仍需保存画布；取消编辑可放弃修改，存储失败保留草稿并显示错误。配置不会自动同步到其他浏览器或设备，未保存草稿不是持久化备份。

## 20 种业务组件与地图

| 分组 | 组件 |
| --- | --- |
| 指标与状态 | 指标卡、仪表盘、目标进度、状态矩阵 |
| 趋势与分布 | 折线图、面积图、柱状图、条形图、环形图 |
| 专业图表 | 多系列折线、堆叠柱状图、双轴组合图、雷达图、散点气泡图、矩阵热力图、漏斗图、矩形树图 |
| 表格与内容 | 数据表格、文本公告、数字时钟 |
| 地图 | 一个共享三维行政区地图 |

文本公告使用配置文字，时钟使用设备时间；其他业务组件可绑定示例或自定义数据。仪表盘以组件目标值为量程；目标进度优先采用每行 `target`，缺少时使用组件目标值。超目标数值保留真实文字，图形填充限制在量程内。环形图用于正值占比。

专业图表可设置配色、图例、数值标签，适用的图表还可设置平滑曲线、区间缩放、系列名称及轴名称。热力图的色标、区间缩放及两轴名称均可配置；树图不显示无效的图例开关，指标卡和仪表盘不显示无效的条数设置。启用区间缩放后使用 `Ctrl + 滚轮`。自定义数据组件切换图表类型会保留业务单位、列名及字段绑定，但应核对新类型需要的字段。从示例改接外部数据时清除演示单位和轴名称，随后填写自己的业务含义。

同类型图表更新数据、调整尺寸或因绘制规模切换渲染方式时，保留当前图例选择和缩放范围；切换类型或关闭缩放按新设置处理。这些是当前展示会话中的交互，不写入模板。

## 模板复用

**模板库**提供 **运行总览、双侧监测、数据分析、业务洞察**四套内置布局。载入替换当前草稿，可以撤销，保存画布后才成为当前浏览器的默认配置。

**我的模板**最多保存 10 份，实际数量还受浏览器空间限制。导出 JSON 包含布局、组件属性、数据绑定、静态数据和接口地址，单个配置最多 2 MB。将文件导入另一个运行本编辑器的项目实例，再调整业务名称、地址和字段映射，即可复用；该格式不与其他大屏工具直接通用。旧 v1 和缺少本轮扩展选项的 v2 配置可导入，显式保存后写入当前 v2 存储。

相对接口地址使用新站点的域名。模板不包含服务端接口实现或授权凭据；不要把敏感业务内容、Token 或密码放入静态数据或导出文件。

## 数据识别与推荐创建

1. 打开 **数据源**，添加 JSON、CSV 或 HTTP GET 源。可粘贴内容、导入文件，或填写接口地址。
2. 点击 **识别数据**或**测试并识别字段**。新源只有一组列表时自动选取路径；发现多个数组时，先在 **选择数据列表**中指定数组，也可填写 `data.rows` 等路径。已有源保留保存的路径，包括空路径所指的根对象；用 **重新识别路径**才重新探测。
3. 核对最多前 5 行预览、字段类型、样例和空值数量。超过 100 个字段时，可搜索路径或翻页；字段列表和下拉候选共用当前页，已选字段始终保留。多个数字段不明确时，在 **图表字段**选择名称、主数值、第二数值；**更多字段**可选时间、系列、坐标等。选择“不使用”后不再自动猜测。改名和同源重读保留手选，切源、内容或路径变化会清空临时选择。数字编号和带前导零的编码不会直接按业务数值猜测。
4. 在 **从这些数据创建组件**中查看可用建议、字段映射与适配后数据，再点击添加。只有必要字段映射明确、数据能满足组件要求时才推荐；歧义、缺失或专业图表校验失败不会强行给出建议。建议表示格式适配，仍需自行确认业务口径。
5. 添加会把源和组件一次应用到画布草稿，可以整体撤销。也可仅保存源，再到现有组件的 **数据绑定**中选择它，用字段候选和 **自动匹配**调整映射，核对前 3 行结果。最后保存画布。

同一源可供多个组件使用，每个组件独立设置映射和汇总方式。仍被业务组件使用的数据源不能删除，隐藏或锁定不会解除绑定，应先调整相关组件。

| 接入方式 | 内容与约束 |
| --- | --- |
| JSON | 根数组、单个对象，或以列表路径读取嵌套数据；多个数组需明确选择。 |
| CSV | UTF-8，首行为唯一非空表头；支持带引号的逗号、换行和双引号。 |
| HTTP | 浏览器 GET，读取 JSON 或 CSV；支持同源相对路径及 HTTP/HTTPS 地址。CSV 可由响应类型或 `.csv` 扩展名识别。 |

最多 40 个数据源；每源最多 1 MB、5,000 行、40 个顶层字段（CSV 为 40 列）。嵌套对象可识别出更多字段，仍受文件大小及 12 层嵌套限制。字段路径使用点号，例如 `device.name`、`metrics.total`，不执行表达式或脚本，不允许 `__proto__` 等特殊属性。

| 组件字段 | 用途 |
| --- | --- |
| `name` | 行名称、分类名称、雷达指标或漏斗阶段 |
| `value` | 主数值；散点图中可作为非负点大小 |
| `time` | 时间文字；趋势类优先作为横轴标签 |
| `status` | 状态文字 |
| `target` | 每行目标值；用于进度或雷达上限 |
| `series` | 多系列图的分组；树图的上级分组 |
| `code` | 行关联的行政区编码；只在当前离线地图范围内跳转 |
| `x`、`y` | 散点图的数值坐标，或热力图的类别坐标 |
| `value2` | 双轴组合图的第二数值 |

指标卡和仪表盘可选 **求和、平均值、第一条**，用于总体数值，不会自动替其他图表分组汇总或排序。基础折线/面积图按输入顺序取末尾 N 条，柱图/条形图取前 N 条；时序和排名排序应由接口完成。表格主数值列支持点击排序，隐藏该列后恢复原始输入顺序。显示数量只限制展示，总体汇总仍使用完整映射结果。专业多系列按横轴类别限制并保留各系列，雷达按指标数限制，热力图按每轴类别数限制且只绘制已有单元格；属性名称对应实际含义。

有效十进制数字和数字字符串可作为数值；`null`、空串、布尔值或无效数字不当成 0。数值组件遇到无效必填值会显示映射错误；状态矩阵与不展示数值的文字表格可以没有 `value`。表格显示“辅助数值”列时，其非空值也必须是有效数字；进度和雷达的数据行目标必须大于 0，未提供目标时使用组件设置。文本公告和时钟不依赖数据源。

基础数字组件可在“内容与样式 → 最多小数位”选择 0–3 位，默认 1 位；设置随画布、模板和 JSON 保存。目标值可输入三位小数，未编辑的导入值失焦后保持原精度，也不会产生一次撤销记录。它限制显示的小数位数，不补尾随零；仪表量程、占比和表格数值列同步使用组件精度。专业图表保留原始数值提示，轴刻度单独保留区分相邻刻度所需的精度。非零数值若按常规显示精度会变成 0，则使用科学记数法，例如 `2E-3` 表示 `0.002`；很大或很小的轴刻度也使用这种表示。原始数据与汇总计算不变。

## 八种专业图表的字段契约

| 类型 | 必需字段 | 可选字段与校验 |
| --- | --- | --- |
| 多系列折线 `multiLine` | `time` 或 `name`、`series`、`value` | 每个系列与类别组合唯一；按输入顺序取最后 N 个类别。某系列缺少类别时留空，不连线补值。 |
| 堆叠柱状图 `stacked` | `name` 或 `time`、`series`、`value` | 每个系列与类别组合唯一；取前 N 个类别。缺少组合留空，不补 0。 |
| 双轴组合图 `combo` | `time` 或 `name`、`value`、`value2` | 每个类别一行；取前 N 行。主副系列名称、副轴单位在图表设置中填写。 |
| 雷达图 `radar` | 至少 3 个 `name` 指标及非负 `value` | `series` 可选；每个系列必须包含所有展示指标且不重复。正数 `target` 可作上限，未提供时使用组件目标值。 |
| 散点气泡图 `scatter` | 有效数值 `x`、`y` | `name`、`series` 可选；`value` 可作非负气泡大小，提示框显示其原值和组件单位；留空使用统一点大小。 |
| 矩阵热力图 `heatmap` | 非空类别 `x`、`y` 与数值 `value` | 每个 X/Y 坐标组合唯一；每轴取前 N 个类别，未提供的坐标格留空。 |
| 漏斗图 `funnel` | `name`、非负 `value` | 按输入阶段顺序展示，不自动重排。全 0 时显示说明。 |
| 矩形树图 `treemap` | `name`、非负 `value` | `series` 可形成上级分组；取前 N 行。全 0 时显示说明。 |

需要唯一类别的专业图遇到重复数据会要求先汇总；缺失必填值、雷达缺少指标等会明确报错，不伪造数值。系列之间未提供的趋势点与热力格也不会补成 0。图表推荐使用同一套校验，业务聚合应在接口或原始数据准备阶段完成。

## 可直接使用的示例

附带文件均为**固定虚构演示快照**，不会根据查询参数筛选，也不会随刷新产生业务更新。

### 基础监测示例

新建 HTTP 源，地址 `/data/examples/monitoring.json?adcode={adcode}`，列表路径填 `rows`，设为手动刷新。字段同名映射，可创建指标、条形图、进度或表格。

```json
{
  "rows": [
    { "name": "华东中心", "value": 862, "target": 1000, "status": "在线", "time": "08:00", "series": "接入设备", "code": "310000" },
    { "name": "华北中心", "value": 715, "target": 900, "status": "在线", "time": "09:00", "series": "接入设备", "code": "110000" }
  ]
}
```

### 专业图表示例

导入 [professional.json](../public/data/examples/professional.json)，或新建 HTTP 源使用 `/data/examples/professional.json`。文件包含七个命名数组；识别后选择下表中的路径，字段按同名映射。一个源只选一条列表路径，需要同时展示不同数组时分别建立源。

| `rowsPath` | 适用类型 | 数据含义与建议设置 |
| --- | --- | --- |
| `seriesTrend` | 多系列折线、堆叠柱状图 | `time/series/value`；区域时段流量示例，可将单位设为 GB。 |
| `comparison` | 双轴组合图 | `name/value/value2`；主系列改为“收入”，副系列改为“成本”，两轴单位设为万元。 |
| `radar` | 雷达图 | `name/series/value/target`；本期、上期四项评分，单位分，显示条数至少 4。 |
| `scatter` | 散点气泡图 | `name/series/x/y/value`；X 轴名称设为“负载 (%)”，Y 轴设为“时延 (ms)”，点大小表示设备数。 |
| `heatmap` | 矩阵热力图 | `x/y/value`；时段与区域活跃度，单位次，包含一个有效的 0。 |
| `funnel` | 漏斗图 | `name/value`；事件处理阶段，单位条，保持输入阶段顺序。 |
| `treemap` | 矩形树图 | `name/series/value`；设备类型与分组，单位台，显示条数设为 6 可看全样例。 |

`{adcode}` 会替换为当前已显示地图的区域编码。真实接口可使用 `/api/monitoring?adcode={adcode}`，由服务端执行区域过滤；静态示例不具备这种业务逻辑。

## 刷新与错误反馈

HTTP 刷新间隔为 0 时不定时轮询，正数最小为 15 秒。源首次使用时读取；页面从隐藏恢复时刷新 HTTP，成功读取且未修改的 JSON/CSV 继续复用。区域切换只重新读取地址含 `{adcode}` 的 HTTP 源，固定 JSON/CSV/HTTP 继续复用结果和原有刷新期限。请求超过 10 秒超时。多个组件共享同一源的请求，增加其他源不会重载未变化的源。页面隐藏暂停轮询并取消未完成请求，旧区域或已删除源的迟到响应不会覆盖当前数据。

接口更新失败时，有上次成功数据的组件保留快照并标记 **更新延迟**；无历史数据时显示错误与重试入口。更换源内容或区域接口的区域后，不会借用旧范围数据。空列表显示空态；读取成功不等于数据具有实时性。

## 技术与交付边界

配置版本仍为 `version: 2`。源结构为 `{ id, name, type, content, url, rowsPath, refreshSeconds }`，`id` 以 `ds_` 开头；组件通过 `binding: { sourceId, fields }` 引用。数据解析和映射位于 `src/dataSources.js`，字段识别与推荐位于 `src/dataInference.js`，专业图校验与选项由 `src/professionalCharts.js` 共享。服务端适配统一字段契约后，多个业务系统可复用组件。

基础图表使用 SVG/CSS，八种专业图表由按需加载的 ECharts 渲染。保留单个共享三维场景；拖动预览按浏览器帧更新，松手提交一次历史。地图可见时提前加载三维引擎，隐藏时不请求该分块。当前本地构建主包为 **110.50 KB gzip**，三维地图引擎为 **283.90 KB gzip**；专业图表与 ECharts 分块为 **235.16 KB gzip**，数据识别分块为 **10.48 KB / 3.99 KB gzip**，共享专业图构建逻辑为 **11.11 KB / 4.75 KB gzip**。这些是构建体积，不是设备帧率或现场性能验收结论。

专业图表资源加载失败时，只在对应组件内显示错误；地图、普通图表与编辑器仍可操作。检查网络后可点击“重新加载页面”；如正在编辑，请先保存画布，未保存的离开保护继续生效。

受保护接口应经同源服务端代理处理鉴权、授权和上游凭据。前端使用 `credentials: 'same-origin'`，不会向跨域接口携带浏览器凭据；跨域服务需允许当前站点访问。接口地址禁止内嵌账号密码及凭据查询参数，编辑器不提供自定义 Authorization 头或 Token 存储。

当前交付包含前端编辑、模板、数据接入和图表能力；服务端权限、租户隔离、集中配置、审批发布与多人协作仍需在目标项目实现。未进行现场部署或设备帧率承诺，浏览器存储和 JSON 交接不替代集中配置管理。

布局交互参考了 [DataV 组件布局](https://www.alibabacloud.com/help/en/datav/datav-6-0/user-guide/widget-layout)中的对齐与分布，以及 [Grafana Canvas](https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/panels-visualizations/visualizations/canvas/)的自由元素与数据绑定思路；专业图表采用 [Apache ECharts](https://echarts.apache.org/handbook/en/concepts/dataset/)的数据维度与图表映射方式。本项目保留自身视觉风格和配置格式。
