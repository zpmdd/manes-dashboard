# 大屏编辑与数据对接

本编辑器在烟灰玻璃、暖白文字和香槟色三维地图的统一风格内配置画布。默认业务数值、地图光柱、连线和热力均为演示内容，接入自己的接口后，只有绑定该接口的业务组件使用外部数据。

## 编辑画布

点击右上角 **编辑大屏**。左侧添加组件或选择图层，右侧修改属性。

- **添加与删除**：点击组件库添加；选中后可复制、删除。每个画布最多 40 个业务组件，另有一个共享三维地图；再次添加地图会恢复显示，不会创建第二个地图实例。
- **移动与缩放**：拖动组件顶部的编辑条移动，拖动选中边框的八个控制点缩放；也可在属性栏输入 X、Y、宽、高百分比。位置限制在画布内，可开关网格吸附。
- **锁定与隐藏**：锁定防止拖动和键盘移动，仍可在属性栏输入尺寸；隐藏组件保留配置，在编辑态可选中，预览及展示态不显示。地图的“删除”是隐藏。
- **层级与外观**：业务组件可置于顶层或底层；可选烟灰玻璃、轻透玻璃、深色面板。修改标题、副标题、单位和表格列名时沿用统一视觉样式。
- **撤销与重做**：使用工具栏按钮，或 `⌘/Ctrl + Z`、`⌘/Ctrl + Shift + Z`；`⌘/Ctrl + D` 复制，方向键微移，`Shift + 方向键` 大步移动，`Delete/Backspace` 删除，`Esc` 取消选择。输入框及打开的对话框不会触发画布快捷键。
- **草稿与保存**：编辑即时反映在当前草稿，**预览**用于检查展示态；**保存画布**才写入当前浏览器。数据源或全局设置面板中的保存仅更新画布草稿，还需保存画布。取消编辑可放弃本次修改；存储失败时草稿保留并显示错误。

修改不会自动同步到其他浏览器、站点或设备。未保存草稿不是持久化备份。

## 组件范围

| 分组 | 组件 |
| --- | --- |
| 指标与状态 | 指标卡、仪表盘、目标进度、状态矩阵 |
| 趋势与分布 | 折线图、面积图、柱状图、条形图、环形图 |
| 表格与内容 | 数据表格、文本公告、数字时钟 |

共 12 种业务组件。文本公告使用配置文字，时钟使用当前设备时间；其余组件可绑定示例或自定义数据。仪表盘使用组件目标值作为量程，目标进度优先使用每行 `target`，没有时使用组件目标值。超目标数值仍保留真实文字，图形填充限制在量程内。环形图用于正值占比。

## 模板复用

**模板库**提供运行总览、双侧监测、数据分析三种内置布局。载入模板会替换当前草稿，可以撤销，保存画布后才成为当前浏览器的默认配置。

**我的模板**最多保存 10 份，实际数量也受浏览器空间限制。导出的 JSON 包含布局、组件属性、数据绑定、静态数据与接口地址，单个画布配置最多 2 MB。将 JSON 导入另一个运行本编辑器的项目实例，再调整业务名称、接口地址和字段映射，即可复用布局；它不是任意第三方大屏工具的通用格式。

相对接口地址会使用新站点的域名。模板不包含服务端接口实现或授权凭据；不要把敏感业务内容、Token 或密码放入静态数据或导出的文件。

## 数据源与字段

在 **数据源**面板新建连接，点击 **测试数据/测试连接**检查前 5 行，再保存到画布草稿。随后选中业务组件，在 **数据绑定**选择源并填写字段路径。同一源可供多个组件使用，各组件独立设置映射和汇总方式。仍被业务组件使用的数据源不能删除，应先调整这些组件的绑定。

| 接入方式 | 内容与约束 |
| --- | --- |
| JSON | 粘贴或导入 `.json`；支持根数组、单个对象，或用列表路径读取 `data.rows` 等嵌套数据。 |
| CSV | 粘贴或导入 UTF-8 `.csv`，首行为唯一非空表头；支持带引号的逗号、换行和双引号。 |
| HTTP | 浏览器发出 GET，读取 JSON 或 CSV；支持同源相对路径及 HTTP/HTTPS 地址。CSV 可由响应类型或 `.csv` 扩展名识别。 |

最多 40 个数据源；每源最多 1 MB、5,000 行、40 列。字段路径使用点号，例如 `device.name`、`metrics.total`，不执行表达式或脚本，也不允许 `__proto__` 等特殊属性。

| 组件字段 | 用途 |
| --- | --- |
| `name` | 行名称、分类名称 |
| `value` | 数值，用于指标、图表、进度和表格 |
| `time` | 时间文字；趋势图优先作为横轴标签 |
| `status` | 状态文字 |
| `target` | 每行目标值，供目标进度使用 |
| `series` | 系列文字，可作为表格列；当前趋势图按单序列绘制，不自动按此字段分组 |
| `code` | 行关联的行政区编码；只有当前离线地图内的编码能跳转 |

汇总可选 **求和、平均值、第一条**，作用于指标类组件的总体数值，不会将趋势图自动分组或重排。折线/面积图按输入顺序取末尾 N 条，柱图/条形图取前 N 条；时序与排名排序应由接口完成。表格数值列支持点击排序。显示条数只限制展示，汇总仍使用该源的完整映射结果。

有效十进制数字或数字字符串可作为数值；`null`、空串、布尔值和无效数字不会当成 0。数值类组件遇到无效 `value` 会显示具体映射错误；状态矩阵可以不提供数值。文本公告和时钟不依赖数据源。

## 可直接使用的示例

新建 **HTTP 接口**数据源，使用项目已附带的固定演示文件：

| 设置 | 值 |
| --- | --- |
| GET 接口地址 | `/data/examples/monitoring.json?adcode={adcode}` |
| JSON 数据列表路径 | `rows` |
| 自动刷新间隔 | 手动刷新 |
| 组件字段映射 | `name → name`、`value → value`、`target → target`、`status → status`、`time → time`、`series → series`、`code → code` |

测试连接后将指标卡、条形图、进度或表格绑定到该源。示例文件的格式如下（节选）：

```json
{
  "rows": [
    { "name": "华东中心", "value": 862, "target": 1000, "status": "在线", "time": "08:00", "series": "接入设备", "code": "310000" },
    { "name": "华北中心", "value": 715, "target": 900, "status": "在线", "time": "09:00", "series": "接入设备", "code": "110000" }
  ]
}
```

`{adcode}` 会替换为当前已显示地图的区域编码。这个示例文件是固定快照，不会根据查询参数筛选，也不会随刷新产生业务更新。真实接口可采用 `/api/monitoring?adcode={adcode}` 并返回相同结构，由服务端执行区域过滤。也可将上述 JSON 粘贴到静态 JSON 源，列表路径同样填写 `rows`。

HTTP 刷新间隔设为 0 表示不定时轮询，正数最小为 15 秒。源首次使用、页面从隐藏恢复或区域切换时会读取；请求超过 10 秒超时。多个组件共享一个源的请求，增加其他源不会重载未变化的源。页面隐藏时暂停轮询并取消未完成请求；旧区域或已删除源的迟到响应不会覆盖当前数据。

接口更新失败时，有上次成功数据的组件保留该快照并标记 **更新延迟**、显示原因；无历史数据时显示错误与重试入口。更换源内容或区域后不会借用旧范围的数据。空列表显示空态，读取成功也不代表数据本身具有实时性。

## 开发对接与部署边界

配置入口为 `src/dashboardConfig.js`，目前导出版本为 `version: 2`，兼容导入原有 v1 配置。每个数据源结构为 `{ id, name, type, content, url, rowsPath, refreshSeconds }`，`type` 是 `json/csv/http`，`id` 以 `ds_` 开头；组件使用 `binding: { sourceId, fields }` 引用。字段转换在 `src/dataSources.js`，共享加载和轮询由 `src/useDataSources.js` 接入。复用项目优先保持字段契约，在服务端适配原始业务系统，避免为不同接口复制组件。

受保护业务接口应经同源服务端代理处理鉴权、授权和上游凭据。前端请求采用 `credentials: 'same-origin'`，不会向跨域接口携带浏览器凭据；跨域服务需自行允许当前站点访问。接口地址禁止内嵌账号密码及凭据查询参数，编辑器不提供自定义 Authorization 头或 Token 存储功能。

当前交付是前端编辑、模板和数据接入能力，未提供服务端权限管理、租户隔离、配置中心、审批发布或多人协作。商业部署需要在目标系统实现这些服务端能力与同源代理，并自行确定数据口径、权限和刷新要求。浏览器本地存储及 JSON 导出可用于个人配置与模板交接，不能作为集中配置管理或审计系统。
