# 专业图表与商业编辑能力验收 · 2026-09-12

本轮在既定烟灰玻璃、香槟文字和共享三维地图上，增加专业图表、数据识别与磁吸多选布局。基于此前已提交的 `e5444a0` 继续迭代；以下为本地验证，未进行生产部署或现场设备验收。

## 实施依据

- [DataV 组件布局](https://www.alibabacloud.com/help/doc-detail/87484.html)：采用多选、六向对齐、水平/垂直等距等成熟编辑方式；本项目另提供同宽同高、画布参照与百分比精确尺寸。
- [Grafana Canvas](https://grafana.com/docs/grafana-cloud/learn-and-build/visualizations/panels-visualizations/visualizations/canvas/) 与[面板数据检查](https://grafana.com/docs/grafana/latest/visualizations/panels-visualizations/panel-inspector/)：采用可见对齐参考线、数据预览和字段选择的操作方式。
- [Apache ECharts 按需导入](https://echarts.apache.org/handbook/en/basics/import/)及[渲染器选择](https://echarts.apache.org/handbook/en/best-practices/canvas-vs-svg/)：引入 Apache-2.0 的 ECharts 6.1.0，按需注册所用图表和组件；通常采用 SVG，实际数据点超过 1000 时选择 Canvas。

实现保留本项目的布局、色板和材质，未复制上述商业产品的商标、素材或产品界面。

## 性能与包体积

| 文件 | 原始 KB | gzip KB | 加载条件 |
|---|---:|---:|---|
| 主文件 | 1399.00 | 394.16 | 首屏 |
| ECharts 渲染组件 | 689.39 | 234.87 | 存在专业图表时 |
| 专业图数据与选项构建 | 10.66 | 4.59 | 专业图或编辑分析时 |
| 数据识别与建议 | 10.15 | 3.88 | 编辑数据/属性时 |
| 属性与模板面板 | 35.14 | 11.31 | 打开编辑器/模板时 |
| 数据源管理面板 | 17.04 | 6.37 | 打开数据源时 |

将编辑专用逻辑从运行时数据层拆出后，主包从本轮中间状态 gzip 400.19 KB 降到 394.16 KB，减少 6.03 KB。数据识别与运行时继续共用解析和 HTTP 读取实现，不维护第二份解析器；专业推荐使用实际图表构建器验证，不维护第二份类别/系列校验逻辑。

拖动以每帧一次 DOM 更新预览，松手仅提交一步历史；专业组件不依赖整个画布配置，纯位置变化不会重新生成数据。字段预览按数据与映射缓存，辅助线刷新不重复转换完整数据集。地图仍按需绘制；常规全国帧为 347 次绘制、575,817 个提交三角面。业务洞察静置 208.78 秒，地图绘制帧保持 6；Chrome Performance 读数中脚本累计 300.90ms，布局累计 160.01ms，JS 已用堆从 40.75MB 到 40.96MB。页面每秒时钟更新仍保留；这只是本机短时样本，不代表长期内存或现场帧率承诺。

基础运行总览模板保存并重载后，Network 实际只记录一个应用脚本请求，未请求 ProfessionalChart、dataInference、EditorPanels 或 DataSourcePanel。
