# 大屏精细化与配置验收 · 2026-09-12

本轮为本地页面实施与浏览器验收；未发布到外部环境，业务数据仍为演示快照。

## 交付变化

- 保留共享三维场景、烟灰玻璃、暖白/香槟配色、材质、地面反射、阴影与离线行政区下钻。
- 删除营销主标题、宣传段落、无业务含义的卡片文字；改为设备总量、在线率、流量趋势、区域排行和运行事件。
- 地图控制面板、业务模块、配置面板和数据适配分别拆分。五个模块使用同一个可复用组件，支持六种展示类型。
- 可配置全局和模块文字、显示隐藏、展示类型、匹配的数据源、3–8条记录、表格列及列名；浏览器保存、JSON导入导出与恢复默认可用。
- 独立时钟不带动大屏更新；地图 hover 仅更新当前行政区，避免整个场景参与协调和接触阴影重复计算。无新增运行依赖，无常驻图表动画或数据轮询。

## 浏览器验收

使用 Chrome；内嵌浏览器在本机不支持 WebGL，未将其用作三维效果依据。

- 在1120×718与原始参考/基线对照图一起检查：材质、暖白文字、胶囊导航、共享背景和三维效果保留；内容密度按新业务模块调整。默认取景向上移动约34px（718px高）给底部数据卡留空，不改变地图精度。
- 检查1920×1080、3840×2160与390×844：无水平溢出；4K场景buffer为2566×1436，与基线像素预算一致。窄屏地图高度独立于下方卡片，默认事件5行完整可见，图层工具与南海附图不被卡片覆盖。
- 模块标题改为“区域设备明细”，切换数据表格、列名改“接入数量”、条数设3；保存并刷新后保持。实际升序显示28、29、30，验证数字排序。
- 切换环形图后合计2048，其他区域合并展示；切换仪表只能选择设备在线率。折线条数改3后仅显示07:00–09:00；隐藏运行事件后模块消失。
- 事件设置8条后保留8个表格行并允许内部手动滚动；无自动跑马灯。
- 修改标题后Escape丢弃草稿，标题不变，焦点回到“大屏配置”。地图弹窗也修复StrictMode下的关闭焦点回归。
- 无效JSON导入被拦截；有效JSON导入在保存前仅更新草稿，保存后标题与隐藏状态生效。导出文件实际下载，2590字节，重新读取通过配置校验。验收后恢复默认配置。
- 全国→湖北→十堰→丹江口：地图与模块按区域更新，区县叶节点排行显示无下级区域。道路可见G70/G59/G209/G241/G316；关闭国道/干线后剩G70、G59、S77、S57。
- 放大、恢复视角、图层控制保持可用；网页原生全屏在本次自动化点击环境被浏览器拒绝，已显示原有窗口全屏提示，未将原生全屏记为通过。
- 质感模式全国常规帧仍为347次绘制调用、575817个提交三角面；时钟持续跳动并到达12:28:50，间隔刷新两次快照帧数仍为23。此证据表示静止地图未被时钟驱动重复绘制，不是FPS提升百分比。
- 最终构建已在 `http://127.0.0.1:5174/#100000` 打开验证；本次最终加载无应用JS错误，保留R3F依赖的Three.Clock弃用警告。编辑期间缺失尚未落盘模块的HMR报错未在最终加载复现。

## 验收边界

配置只存当前浏览器；跨设备用JSON导入导出，未接入服务端配置中心。业务数据适配集中在`src/widgetData.js`，尚未对接真实监控API。未验收现场显卡的长期运行帧率、所有行政区的视觉形态或地图时效/精确坐标。
