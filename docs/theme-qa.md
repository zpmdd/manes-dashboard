## 保存与兼容

- 配色作为编辑草稿，支持撤销、重做，保存画布后保留在当前浏览器，取消则回到已保存配置。
- 配色随画布 JSON 和模板往返保存；旧配置缺少 `theme` 时使用烟灰香槟，非法配色拒绝导入。换色不改布局、数据源、字段绑定或地图视角。
- 专业图表的「跟随大屏配色」沿用原配置值 `champagne`。原先明确选择海洋/森林图表色板的组件继续固定使用该色板。
- 告警、离线、负数等状态颜色保留语义；离线道路瓦片保留原图颜色及地名文字，周围界面随主题变化。
