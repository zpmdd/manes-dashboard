| 版本 | 内容 |

## 验证边界

这些是本机模拟数据、真实浏览器操作与本地 Git/SVN 事务验证，不代表生产部署或真实业务准确性验收。未做负载/长时间运行、真实设备 GPS 坐标系校准、多人实时配置同步或真实窗口全屏验收。当前只支持一个限行区域和一个每日时段；跨午夜已覆盖测试。连续命中事件不能直接作为实际驶离时刻或执法结论。

远端发布成功以 SVN 提交说明、`dashboard:git-commit` 根属性及 `npm run sync:status` 的共同基线为准；发布命令会再次验收并逐文件核对，只有完成核对才推进基线。
