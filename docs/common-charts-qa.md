# 常用报表图表与车辆状态饼图验收

验收日期：2026-09-18（北京时间）。

## 实现范围

- 业务组件由 20 种补齐为 28 种，按指标、趋势、占比、统计、内容分组；增加饼图、玫瑰图、分组柱状图、堆叠面积图、百分比堆叠图、直方图、箱线图、瀑布图。
- 复用已安装的 Apache ECharts 6.1.0，按需注册新增专业图表，没有增加依赖。箱线统计使用 ECharts 原生数据变换；基础饼图保留 SVG 键盘与车辆定位交互。
- 新增“趋势与占比”和“统计与增减”两套布局；基础版现有 6 套通用布局，道研另有车辆快照布局。新增原始样本、收支变动示例和外部 JSON 样例。
- 新类型共用添加、类型切换、映射校验、数据预览、主题字体、保存和导入导出。累计溢出、负值占比、空数据、重复系列均提供明确处理。
- 道研第二卡默认切换为饼图；用户原有 localhost:5175 画布也已通过编辑器切换并保存，重新加载确认保留三卡布局与车辆数据源。

## 饼图可读性修订

- 原小饼图与底部图例分占高度，改成最多四分类且每侧不超过两项时使用完整卡片高度。外引连线直接展示名称、实际数值及占比；密集分类使用完整图例，避免密集标签堆叠。
- 加入扇区间隙、厚度、主题渐变和柔和阴影。读数使用明亮前景色，数字沿用 Michroma。
- 用户 2560 × 1267 视口下，主饼体直径约 186px（修订前约 127px），在原卡片内放大约 46%；仍按数据比例绘制 80% / 20%。
- 车辆总数保持数字雕塑，不重复行驶与静止数量。

## Chrome 实际验收

使用用户 Chrome 扩展连接，在专用测试页验收后清理；没有修改用户 DevTools 或系统配置。

- 道研正式构建：1920 × 1080 桌面、390 × 844 窄屏均完整显示。窄屏内容宽 375px，小于 390px 视口，无横向溢出；三张卡片和外引文字未裁切。
- 键盘 Enter 选择“行驶 1 辆（20%）”，地图与列表选中车辆 3；点击“静止”外引文字，地图与列表选中车辆 1、2、4、5。
- 基础版正式构建：新增模板均可打开；多分类饼图显示 8 条对应图例，切换深海青碧后各图表和玻璃边框同步换色。
- 本轮两个构建页面捕获的控制台错误均为空。临时模板及配色草稿已撤销，用户原有页面保留最终饼图。

## 后续修订：倾斜饼面、地图下钻与三级位置

- 饼面纵向比例调整为 0.72，配合侧面厚度形成轻微俯视透视；外引线连接实际扇区边缘，文字保持正立。
- 根据用户近景反馈，改用前半圆可见弧段构造真实外圈侧壁，替代向下复制整个扇区的伪厚度；侧壁先于全部顶面绘制，各自共用投影。小扇区转向前侧，两块都露出等高厚度，径向仅轻微分离 1.2 个 SVG 单位；无黑色描边，仅保留细暖色高光。回归断言覆盖双扇区侧壁、绘制顺序及顶面与侧壁对齐。
- 修复全国视图下状态分组只高亮、不定位的问题。点击“行驶”下钻朝阳区并选择车辆 3；点击“静止”从区县返回全国地图并聚焦北京、天津的车辆 1、2、4、5。切换地图层级后再执行相机定位，避免旧区县范围影响车群显示。
- 速度列表的车辆名称后增加定位图标和三级地名。现有快照解析为车辆 1–4“北京-北京-朝阳区”、车辆 5“天津-天津-蓟州区”；普通省市区验证为“广东-广州-天河区”。按 GPS 读取现有离线边界，同一批查询复用文件请求；数据变化会取消旧结果。状态分组排行不附加单车地名。
- `npm run verify` 再次通过：123 项应用测试、地图检查、两版构建、4 项 Sites 检查及独立产物检查。增加真实区县与地名断言、跨区域及同区县车群定位、全国分类点击和位置无障碍文本回归。
- Chrome 实测桌面 2560 × 1323、窄屏 390 × 844。窄屏地名完整显示且无横向溢出；点击车辆 5 下钻蓟州区，Space 激活“行驶”扇区下钻朝阳区；桌面跨区域车群全部可见。
