每套展示图为 2880 × 1920 PNG，含主字标、24 / 40 / 64 px 图形预览、界面组合和浅底应用。图形原稿为 1254 × 1254；01 与 03 含透明通道，02 为清理后的不透明烟灰底。浅底示例使用深色图标底座，不代表已交付全套单色反白文件。

用户已选定③「构域」，已按选中结构精修矢量轮廓、单色版和 favicon，并落地大屏项目，见[当前品牌资源](../README.md)。本目录保留当时的三套概念提案，生成原稿近看可能有轻微色阶或边缘噪点；正式使用请取当前品牌资源中的 SVG。

[打开三套对照](review/index.html)。排版来源为 `render-concepts.mjs` / `artboards.html`；渲染脚本同时检查图片加载、字体加载、三套输出与内容边界。`image-bounds.json` 用于统一视觉尺寸，不改动生成图片像素。`drafts/` 为未选入本轮对照的曲线探索。
